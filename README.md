# HTML RVM

HTML RVM — независимая браузерная виртуальная машина Модели Отношений (Relation Model VM). Проект находится на стадии архитектурного bootstrap: **интерпретатор пока не реализован**.

## Назначение

Сохранить семантику jsonRVM/phprvm (сущности, отношения, контексты исполнения, ссылки, программы как данные), но не переносить зависимость от локальных файлов, PHP eval или C++ адресов памяти.

HTML RVM не реализует и не импортирует криптографию, криптоцепочки, физические адреса (ID,H) или HTML DBMS. Работа с JSON организована через DocumentPort/1, чтобы VM могла одинаково запускаться с MemoryDocumentProvider, обычным файловым провайдером и внешней DBMS.

**Принцип исполнения:** HTML RVM работает над отдельным временным изменяемым JSON-состоянием, инициализированным из неизменяемого снимка провайдера. Исполнение отношений может самомодифицировать этот JSON с высокой частотой; ни одно такое изменение само по себе не пишет в DBMS. Сохранение представляется отдельной явной сущностью/намерением Модели Отношений и проходит через доверенный хост с отдельной writer capability. Автоматической записи после каждого изменения или завершения исполнения нет.

HTML DBMS остаётся самостоятельной JSON-СУБД и не импортирует HTML RVM. Их сочетание обеспечивается необязательным внешним адаптером; Root Registry не является частью ядра VM.

## Состояние

- Документирован **кандидат** DocumentPort/1 — не реализованный контракт и не принятый релиз.
- Канонические нормативные требования — в каталоге requirements/*.rg.yaml. Остальные документы объясняют и иллюстрируют их, но не заменяют.
- RepoGuard v6.0.1 подключается через immutable commit SHA; первый PR содержит bootstrap-требования и требует отдельной проверки первоначальной authority.
- Нет принятого production приложения, готового VM, DBMS адаптера или доказанных контрактных тестов.
- Первый предполагаемый потребитель — обезличенная касса; второй — склад.
